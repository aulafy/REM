# Initial public foundation

This publication introduces a clean source history for REM. It contains the application, reusable module entry points, synthetic tests/evaluations, a curated AWOS source snapshot, an English interface, and English documentation.

Earlier project names remain in protocol/data identifiers for compatibility. Spanish prompts, synthetic business records, test names, and acceptance cases are preserved deliberately. The interface translation does not claim measured English-language assistant capability. Stored user/model text is not translated or rewritten to appear correct.

The source snapshots and selected file hashes are recorded in PUBLICATION.json. Historical internal handoffs, private model results, databases, credential files, old Git objects, and installers are not published. AI assistance is acknowledged separately in AI_ASSISTANCE.md.

Verification evidence is recorded in architecture/verification.md. A browser visual pass is not claimed for this publication. No installed instance, real account, real data, or distribution artifact is changed by source publication.
