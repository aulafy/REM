# Module implementation references

Use the [architecture module guide](../architecture/modules.md), the reviewed entry points in `modules/`, `public/module-contract.js`, `src/rem-modules.js`, and `runtime/awos/pymes/src/rem-module-sdk.ts`.

The current four-module library is a synthetic-host integration. It includes expected revisions, explicit capabilities, idempotent configuration commands, and history. It does not install arbitrary code or enable real sending. Documents and appointments are future work.
