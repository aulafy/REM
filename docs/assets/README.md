# REM — recursos gráficos

Listos para subir a `aulafy/REM` (sugerido: `docs/assets/`).

| Carpeta / archivo | Uso |
|---|---|
| `rem-logo.svg`, `png/rem-logo.png` (512), `png/rem-logo-1024.png` | Logo (avatar de GitHub, icono de app) |
| `rem-logo-dark.svg`, `png/rem-logo-dark.png` | Variante para fondos claros/oscuros alternativos |
| `png/favicon.ico`, `png/favicon-16/32/180.png` | Favicon y apple-touch-icon |
| `rem-wordmark-{light,dark}-{es,en}.svg/png` | Logo + nombre + lema (cabecera del README) |
| `rem-wallpaper-1600x900-{es,en}`, `rem-wallpaper-1920x1080-{es,en}` | Portada de artículos / social preview (GitHub: Settings → Social preview) |
| `screenshots/*.png` | Capturas 2x de la app con datos ficticios (modo oscuro) |

Colores: azul `#2448B0`, verde `#8BD8AD`, fondo `#171719` / `#F5F5F3` (tokens de la app).
Las capturas usan solo datos sintéticos (`@example.test`, «Ficción NNN»).

Ejemplo para el README:

```md
<p align="center"><img src="docs/assets/rem-wordmark-light-en.png" width="380" alt="REM"></p>

![Today](docs/assets/screenshots/today.png)
```

> **Nota:** las capturas muestran la interfaz actual (inglés, «Experimental email»). Se regenerarán tras los pasos 1 (bilingüe) y 3 (Hoy como centro de trabajo) del plan.
